## 什么是机器学习？

机器学习是人工智能的一个分支，它让计算机能够从数据中学习，而不需要明确编程。机器学习的核心思想是：通过大量数据训练出一个模型，让这个模型能够对新数据做出预测。

机器学习主要分为三类：

1. 监督学习（Supervised Learning）：训练数据有标签。例如，给模型看 10000 张标注了"猫"或"狗"的图片，让它学会区分猫和狗。常见算法：线性回归、决策树、随机森林、支持向量机、神经网络。

2. 无监督学习（Unsupervised Learning）：训练数据没有标签。模型自己从数据中发现模式。例如，给模型一堆用户购买记录，让它自动把用户分成几个群体。常见算法：K-Means聚类、DBSCAN、主成分分析（PCA）。

3. 强化学习（Reinforcement Learning）：智能体通过与环境交互来学习。做对了给奖励，做错了给惩罚。AlphaGo下围棋就是用强化学习训练的。

## 什么是深度学习？

深度学习是机器学习的一个子集，使用多层神经网络来学习数据的层次化表示。

关键概念：
- 神经网络（Neural Network）：由多个"神经元"层组成的计算模型。输入层接收数据，隐藏层做特征提取，输出层给出结果。
- 反向传播（Backpropagation）：计算预测值和真实值之间的误差，然后把这个误差从输出层反向传播到输入层，更新每一层的参数。
- 激活函数（Activation Function）：ReLU、Sigmoid、Tanh等，给神经网络引入非线性。
- 损失函数（Loss Function）：衡量模型预测有多"错"。MSE用于回归，交叉熵用于分类。

## 什么是 Transformer？

Transformer 是 2017 年 Google 提出的深度学习架构，论文标题是"Attention Is All You Need"。它是现在几乎所有大语言模型的基础架构，包括 GPT、Claude、BERT、DeepSeek 等。

Transformer 的核心创新是"自注意力机制"（Self-Attention），让模型在处理一个词时，能够同时关注输入序列中的所有其他词，从而捕捉长距离的依赖关系。

Transformer 由编码器（Encoder）和解码器（Decoder）组成：
- 编码器：理解输入文本，提取特征
- 解码器：根据编码后的特征生成输出文本

GPT 只用了解码器部分，BERT 只用了编码器部分。

## 什么是 RAG？

RAG（Retrieval-Augmented Generation，检索增强生成）是一种让大语言模型在回答问题之前先"查资料"的技术。

RAG 的工作流程：
1. 文档加载与分块：将文档切分成小段落
2. 向量嵌入（Embedding）：将每个文档块转换为数学向量
3. 向量存储：存入向量数据库（如 Chroma、Milvus、Pinecone）
4. 检索：用户提问时，将问题也转为向量，在数据库中搜索最相似的文档块
5. 增强生成：把检索到的文档块和问题一起发给 LLM，让它基于可靠信息回答

RAG 的主要优势：
- 减少幻觉：LLM 基于真实文档回答，而不是凭空编造
- 知识更新：不需要重新训练模型，更新文档就能更新知识
- 可溯源：每个回答都能追溯到具体文档来源

## 什么是 LangChain？

LangChain 是目前最流行的 LLM 应用开发框架，由 Harrison Chase 于 2022 年创立。它提供了一套标准化的接口来构建 LLM 驱动的应用。

LangChain 的核心模块：
1. Model I/O：统一封装各种 LLM（OpenAI、Anthropic、HuggingFace 等）
2. Retrieval：RAG 相关功能（文档加载、文本分割、向量存储、检索器）
3. Chains：将多个 LLM 调用串联起来
4. Agents：让 LLM 自主决定使用哪些工具、以什么顺序执行
5. Memory：对话记忆管理

LangChain 的主要竞品是 LlamaIndex（偏重数据索引和检索）和 Dify（低代码平台）。

## 什么是 Agent？

AI Agent（智能体）是能够自主感知环境、做出决策并执行行动的系统。在大模型出现之前，Agent 主要基于强化学习。现在，基于 LLM 的 Agent 成为主流。

LLM Agent 的核心能力：
1. 工具使用（Tool Use/Function Calling）：调用外部 API、数据库、搜索引擎
2. 规划（Planning）：将复杂任务分解为子任务，制定执行计划
3. 记忆（Memory）：记住对话历史、用户偏好、之前的执行结果
4. 反思（Reflection）：评估自己的输出质量，必要时修正

ReAct（Reasoning + Acting）是目前最主流的 Agent 推理模式，它将推理过程和行动交替进行——思考→行动→观察→思考→行动→观察，直到任务完成。

## 什么是向量数据库？

向量数据库是专门存储和检索向量（Embedding）的数据库。与传统的 SQL 数据库不同，向量数据库不是做精确匹配，而是做"相似度搜索"。

例如：
- SQL查询：找出所有 city = "北京" 的记录
- 向量查询：找出与"北京天气怎么样"这个意思最相似的 3 个文档块

常用的向量数据库：
- Chroma：轻量级开源，适合原型和中小规模项目
- Milvus：企业级，支持分布式和 GPU 加速
- Pinecone：全托管云服务，无需自建
- Qdrant：Rust 编写，性能优秀
- FAISS：Meta 开源，纯库形式（不是数据库）
